## 基本

- **入站** 块在本机接收连接，例如 SOCKS5 端口。
- **出站** 块是流量离开的地方：直连、其他代理或隧道。
- 在 **画布** 上，把块的输出拖到另一个块的输入即可连接。双击块进行编辑。
- 用块上的 **运行** 或托盘菜单启动入站。

## 在应用中使用

- 右键入站 → **复制客户端用的地址/链接**，填到应用的代理设置里。
- 整台电脑：右键 HTTP 入站 → **用作电脑代理**（运行期间作为 Windows 系统代理）。
- 手机或其他电脑：复制 Shadowsocks、Hysteria2 或 WireGuard 服务器入站的链接。

## 中间的块

- **Router**：按域名、IP、程序或国家设规则，每条规则有自己的输出。
- **IF**：一个条件（满足 / 否则），或像断网保护那样的手动开关。
- **分组**：把多个出站当作一个：最快的、第一个可用的或手动选择。
- **经由**：出站自身的连接经过另一个出站（链式）。
- **直通** 和 **无线配对**：只用来整理连线。

## 画布快捷键

| 按键 | 操作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| F2 · Ctrl+D · Delete | 重命名 · 复制 · 删除 |
| ← → | 沿连线的上一个 / 下一个块 |
| ↑ ↓ | 上方 / 下方的块（← → 之后有多个去向时切换去向） |

## VPN 绕行 (Windows)

即使整台电脑开着 VPN，把块的**网络接口**设为 **VPN 之外**，该块就会绕过 VPN 发出。由直接连接到网卡的小型 Hyper-V 虚拟机发送这些流量（**设置 > VPN 绕行**：网卡、内存、地址；点击 **创建** 时会先征求你的同意）。需要已开启 Hyper-V 的 Windows 专业版、企业版或教育版。

这些流量会暴露你的真实 IP 地址，VPN 的断网保护和 DNS 保护不适用；对于公司或学校的 VPN，这可能违反其规定。开启后产生的后果由你自行负责。

## 其他电脑使用

把入站地址设为 `0.0.0.0` 并开启密码。Windows 防火墙规则在 **设置** 中。

## 关闭

X 只隐藏窗口，代理在托盘中继续运行。从托盘菜单退出。
