## 基本

- **接收端** 區塊在本機接收連線，例如 SOCKS5 連接埠。
- **傳出端** 區塊是流量離開的地方：直連、其他代理或通道。
- 在 **畫布** 上，把區塊的輸出拖到另一個區塊的輸入即可連接。按兩下區塊進行編輯。
- 用區塊上的 **執行** 或系統匣選單啟動接收端。

## 在應用程式中使用

- 在接收端按右鍵 → **複製用戶端用的位址/連結**，填到應用程式的代理設定中。
- 整台電腦：在 HTTP 接收端按右鍵 → **用作電腦代理**（執行期間作為 Windows 系統代理）。
- 手機或其他電腦：複製 Shadowsocks、Hysteria2 或 WireGuard 伺服器接收端的連結。

## 中間的區塊

- **Router**：依網域、IP、程式或國家設規則，每條規則有自己的輸出。
- **IF**：一個條件（符合 / 否則），或像斷網保護那樣的手動開關。
- **群組**：把多個傳出端當作一個：最快的、第一個可用的或手動選擇。
- **經由**：傳出端自身的連線經過另一個傳出端（串接）。
- **直通** 和 **無線配對**：只用來整理連線。

## 畫布快速鍵

| 按鍵 | 動作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 復原 / 重做 |
| F2 · Ctrl+D · Delete | 重新命名 · 複製 · 刪除 |
| ← → | 沿連線的上一個 / 下一個區塊 |
| ↑ ↓ | 上方 / 下方的區塊（← → 之後有多個去向時切換去向） |

## 線路直連

即使整台電腦開著 VPN，把區塊的**網路介面**設為 **線路直連**，該區塊就會繞過 VPN 送出。由直接連接到網路卡的小型 Hyper-V 虛擬機送出這些流量（**設定 > 線路直連**：網路卡、記憶體、位址；按下 **建立** 時會先徵求你的同意）。Windows：需要 Hyper-V（專業版、企業版或教育版）。Linux：不用虛擬機，使用網路命名空間（`ip`，透過 pkexec 取得 root）。macOS（Apple 晶片）：尚未在實機上測試。

這些流量會暴露你的真實 IP 位址，VPN 的斷線保護和 DNS 保護不適用；對於公司或學校的 VPN，這可能違反其規定。開啟後產生的後果由你自行負責。

## 其他電腦使用

把接收端位址設為 `0.0.0.0` 並開啟密碼。Windows 防火牆規則在 **設定** 中。

## 關閉

X 只隱藏視窗，代理在系統匣中繼續執行。從系統匣選單結束。
