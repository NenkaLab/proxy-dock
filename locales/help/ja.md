## 基本

- **受信側** ブロックはこの PC で接続を受けます。例: SOCKS5 ポート。
- **送信側** ブロックは通信の出口です。Direct、別のプロキシ、トンネルなど。
- **キャンバス** でブロックの出力を別のブロックの入力へドラッグしてつなぎます。ダブルクリックで編集します。
- 受信側はブロックの **実行** やトレイメニューでオンにします。

## アプリで使う

- 受信側を右クリック → **クライアント用のアドレス/リンクをコピー** し、アプリのプロキシ設定に入れます。
- PC 全体: HTTP 受信側を右クリック → **PC のプロキシとして使う** (動作中は Windows のシステムプロキシ)。
- スマホや他の PC: Shadowsocks・Hysteria2・WireGuard サーバー受信側のリンクをコピーして使います。

## 間に置くブロック

- **Router**: ドメイン・IP・プログラム・国ごとのルール。ルールごとに出力があります。
- **IF**: 条件 1 つ (一致 / それ以外)、またはキルスイッチのような手動のオン/オフ。
- **グループ**: 複数の送信側を 1 つとして。最速、最初に使えるもの、手動選択。
- **経由**: 送信側の接続を別の送信側を通して出します (チェーン)。
- **パススルー** と **ワイヤレスペア**: 配線を整理するだけです。

## キャンバスのキー

| キー | 動作 |
|---|---|
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| F2 · Ctrl+D · Delete | 名前を変更 · 複製 · 削除 |
| ← → | 接続をたどって前 / 次のブロック |
| ↑ ↓ | 上 / 下のブロック (← → の後、行き先が複数なら別の行き先) |

## 回線直結

PC 全体で VPN がオンでも、ブロックの**ネットワークインターフェイス**を **回線直結** にすると、そのブロックだけ VPN の外へ出ます。ネットワークカードに直接つないだ小さな Hyper-V 仮想マシンがその通信を送り出します（**設定 > 回線直結**：ネットワークカード、メモリ、アドレス。**作成** を押すと先に同意を求めます）。Windows: Hyper-V (Pro / Enterprise / Education) が必要です。Linux: VM なしでネットワーク名前空間を使います (`ip`、pkexec による root)。macOS (Apple シリコン): 実機ではまだ試していません。

この通信では実際の IP アドレスが見え、VPN のキルスイッチや DNS 保護は適用されません。会社や学校の VPN では規則違反になる場合があります。オンにした結果はユーザーの責任です。

## 他の PC から使う

受信側のアドレスを `0.0.0.0` にし、パスワードをオンにします。Windows ファイアウォールのルールは **設定** にあります。

## 閉じる

X はウィンドウを隠すだけで、プロキシはトレイで動き続けます。終了はトレイメニューから。
