## 기본

- **받는 쪽** 블록은 이 PC에서 연결을 받습니다. 예: SOCKS5 포트.
- **내보내는 쪽** 블록은 트래픽이 나가는 곳입니다. Direct, 다른 프록시, 터널 등.
- **캔버스**에서 블록의 출력을 다른 블록의 입력으로 끌어 잇습니다. 블록을 더블클릭하면 편집합니다.
- 받는 쪽은 블록의 **실행** 체크나 트레이 메뉴로 켭니다.

## 앱에서 쓰기

- 받는 쪽 블록 우클릭 → **클라이언트용 주소/링크 복사** 후 앱의 프록시 설정에 넣습니다.
- PC 전체: HTTP 받는 쪽 우클릭 → **PC 프록시로 사용** (켜져 있는 동안 Windows 시스템 프록시).
- 휴대폰·다른 PC: Shadowsocks, Hysteria2, WireGuard 서버 받는 쪽의 링크를 복사해 씁니다.

## 중간 블록

- **Router**: 도메인, IP, 프로그램, 국가별 규칙. 규칙마다 출력이 따로 있습니다.
- **IF**: 조건 하나(맞으면 / 아니면) 또는 킬 스위치 같은 수동 켜기/끄기 스위치.
- **그룹**: 여러 내보내는 쪽을 하나처럼. 가장 빠른 것, 먼저 되는 것, 직접 고른 것.
- **경유**: 내보내는 쪽의 연결이 다른 내보내는 쪽을 거쳐 나갑니다(체인).
- **패스스루**와 **무선 연결 쌍**: 선 정리용입니다.

## 캔버스 단축키

| 키 | 동작 |
|---|---|
| Ctrl+Z / Ctrl+Y | 실행 취소 / 다시 실행 |
| F2 · Ctrl+D · Delete | 이름 변경 · 복제 · 삭제 |
| ← → | 연결을 따라 이전 / 다음 블록 |
| ↑ ↓ | 위 / 아래 블록 (← → 뒤 갈래가 여럿이면 다른 갈래) |

## VPN 우회 (Windows)

PC 전체에 VPN이 켜져 있어도 블록의 **네트워크 인터페이스**를 **VPN 밖으로**로 하면 그 블록만 VPN 밖으로 나갑니다. 네트워크 카드에 직접 연결한 작은 Hyper-V 가상 머신이 그 트래픽을 내보냅니다(**설정 > VPN 우회**: 네트워크 카드, 메모리, 주소. **만들기**를 누르면 먼저 동의를 받습니다). Hyper-V가 켜진 Windows Pro·Enterprise·Education이 필요합니다.

이 트래픽은 실제 IP 주소가 드러나고 VPN의 킬스위치·DNS 보호가 적용되지 않습니다. 회사·학교 VPN이라면 정책 위반일 수 있습니다. 켜서 생기는 결과는 사용자 책임입니다.

## 다른 PC에서 쓰기

받는 쪽 주소를 `0.0.0.0`으로 하고 비밀번호를 켭니다. Windows 방화벽 규칙은 **설정**에 있습니다.

## 닫기

X는 창만 숨기고 프록시는 트레이에서 계속 돕니다. 종료는 트레이 메뉴에서 합니다.
